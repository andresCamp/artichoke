# Project

## Product Knowledge

Product context lives in the `osis/` directory. Consult these before making product decisions or significant changes:

- `osis/twin.md`: agent-readable operational map of the product
- `osis/manifesto.md` (if present): product declaration
- `osis/mvp/thesis.md` (if present): current version hypothesis
- `osis/mvp/core/product.md` (if present): current version definition
- `osis/mvp/core/{iteration}/brief.md` (if present): current iteration bet

Other docs (brand, design-system, strategy, charter) appear only when they earn a place in the product. Active version: ``. Say "osis" to consult the product expert.
